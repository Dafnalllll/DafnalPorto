Portfolio pribadi yang dibuat dengan gaya modern, elegan, dan berani. Proyek ini menampilkan pengalaman kerja, kemampuan teknis, serta proyek-proyek yang relevan dalam bentuk landing page yang interaktif dan berkesan.

## ✨ Highlights

- Tampilan landing page yang cinematic dan premium
- Navigasi multi-page dengan React Router
- Animasi halus dan loading screen yang modern
- Layout responsif untuk desktop, tablet, dan mobile
- Struktur kode yang rapi dan mudah dikembangkan
- Fokus pada branding personal dan showcase project

## 🧩 Tech Stack

- React 19
- Vite
- React Router DOM
- Framer Motion
- GSAP
- Anime.js
- Tailwind CSS
- Lucide React
- Three.js

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Jalankan aplikasi di local

```bash
npm run dev
```

Aplikasi akan berjalan di URL lokal yang ditampilkan di terminal.

### 3. Build untuk produksi

```bash
npm run build
```

### 4. Preview build produksi

```bash
npm run preview
```

## 🎯 Ide Utama

Project ini dirancang bukan hanya sebagai portfolio biasa, tetapi sebagai representasi visual dari identitas dan kemampuan kreatif pemiliknya. Dengan kombinasi animasi, layout modern, dan pengalaman pengguna yang halus, portfolio ini dibuat agar meninggalkan kesan yang kuat sejak halaman pertama dibuka.
